一、概述

夏夜工具集（xiaye.xyz，以下简称「本站」）是一个由个人独立维护的免费在线小工具站点，并提供一款 Windows 桌面程序「实时美颜相机」（以下简称「本程序」）。

我们非常重视你的隐私。本声明说明我们收集什么、不收集什么、为什么，以及你对个人信息拥有的权利。一句话概括：本站不收集你的个人信息，你使用在线工具时输入的内容也不会离开你的设备。

二、我们在网站上收集的信息

1. 你主动提交的信息（唯一的例外）

本站设有「反馈与建议」功能。当你主动使用它时，可以自愿填写：

  • 昵称（选填，最多 30 字）
  • 联系方式（选填，最多 60 字，如 QQ / 邮箱 / 微信）
  • 反馈内容（必填，最多 2000 字）

用途：仅用于回复你本人的反馈、排查你报告的问题。昵称与联系方式均为选填，不填写也可以正常提交。

2. 服务器自动记录的访问日志

与绝大多数网站一样，服务器会记录：IP 地址、浏览器 User-Agent、访问时间、请求的路径与状态码。

用途：仅用于安全防护、防止滥用攻击、排查服务故障。保留期限：不超过 30 天，之后自动轮转删除。

3. 存储在你浏览器本地的数据

本站使用浏览器 localStorage 保存少量偏好设置，例如：夜间模式开关、常用工具的点击次数、最近使用的颜色、汇率缓存。

这些数据仅保存在你自己的浏览器中，不会上传到服务器，你清除浏览器数据即可删除。

三、我们不收集的信息

  • 无账号系统：本站不需要注册或登录，不收集用户名、密码、手机号、邮箱。
  • 无跟踪与广告：本站不设置用于追踪的 Cookie，不含第三方统计、分析或广告脚本，不含任何跨站跟踪代码。
  • 在线工具的输入内容不上传：图片工坊、PDF 工具箱、OCR、Markdown、JSON/Base64 转换等所有在线工具均为纯前端实现，你上传或输入的图片、文本、文档全部在你的浏览器本地处理，不会被发送到服务器。
  • 不收集精确地理位置、通讯录、短信、相册、剪贴板等任何系统隐私数据。

四、桌面程序「实时美颜相机」

本程序为 Windows 10 / 11 64 位桌面软件，可从 https://xiaye.xyz/beauty-cam/ 下载。

1. 摄像头权限

本程序的核心功能是实时美颜，因此需要访问你的摄像头。摄像头访问必须经你在 Windows 系统中明确授权后才会启用；你随时可以在「设置 → 隐私和安全性 → 相机」中关闭该权限。

画面仅在你的电脑本机内存中实时处理，不录制、不保存、不上传、不传输到任何服务器。我们不收集、不存储、不分析任何人脸图像或面部特征数据。

2. 自动更新

本程序启动时会向 https://xiaye.xyz/beauty-cam/version.json 请求一次版本清单，用于判断是否有新版本。该请求仅包含版本号、系统架构等运行所必需的信息，不包含任何个人数据。

3. 本地文件

本程序产生的运行日志与截图保存在安装目录下的 logs\ 与 captures\ 文件夹中，仅存在于你的电脑上，卸载时可一并删除。

关于「发布者：未知」：本程序的安装包目前未做商业代码签名，因此 Windows 与 Edge 可能提示「未知发布者」或「通常不会下载」。这属于未签名软件的常规信誉提示，并非病毒或安全警告，你可以核对本站公布的 SHA256 校验值确认文件未被篡改。
