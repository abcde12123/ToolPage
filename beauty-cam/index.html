实时美颜相机

Windows 桌面程序 · 也可以直接在网页上试用

Windows 读取中…

打开摄像头就能实时美颜：磨皮、美白、瘦脸、大眼、红润、滤镜和 AR 贴纸， 参数可以随手拖，也可以用预设一键切换。画面完全在本机处理，不联网、不上传。

  • ✨ 磨皮 / 美白：引导滤波 + 高反差保留，自动排除头发、眉毛、眼睛和嘴唇
  • 🙂 瘦脸 / 大眼：平滑变形，只动脸部、背景不乱扭
  • 🎨 滤镜与红润：自然 / 冷白 / 暖阳 / 复古 / 清新，浓度可调
  • 🐱 AR 贴纸：爱心、星星、皇冠、猫耳、墨镜…可拖动、缩放、旋转
  • ⚙️ 13 项高级参数 + 预设保存，支持一键截图
